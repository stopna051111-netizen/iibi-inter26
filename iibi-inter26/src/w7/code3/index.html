3-1. 컨테이너 쿼리를 통한 동시 다형성 (공간 반응형)

브라우저 창 크기를 줄이지 마세요! 좌측의 넓은 본문 영역과 우측의 좁은 사이드바 영역에 완전히 똑같은 HTML 구조의 카드가 들어있지만, 컨테이너 쿼리 덕분에 한 화면 안에서 각각 가로형과 세로형으로 동시에 다르게 렌더링됩니다.

넓은 본문 (350px 초과 ➔ 가로형 유지)
THUMB

모던 웹 디자인 시스템

공간이 넉넉하므로 가로 배치 구조를 유지하여 시각적 정보를 효율적으로 전달합니다.

좁은 사이드바 (350px 이하 ➔ 세로형 자동 전환)
THUMB

3-2. 조상 탐색(container-name)과 콘텐츠 중심(ch 단위) 설계

이 아티클 박스는 content-box와 ch 단위를 사용하여 내부 텍스트가 가로로 45글자 미만으로 좁아지면 레이아웃이 꺾이도록 설계되었습니다. 중간에 여러 겹의 div가 있어도 지정한 조상 컨테이너(article-box)의 너비를 정확히 찾아 작동합니다.
